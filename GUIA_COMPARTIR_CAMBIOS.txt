⚠️ IMPORTANTE - EVITAR PROBLEMAS
═══════════════════════════════════════════════════════════════════════════════

✅ SI algo no funciona:

1. Nunca hagas push directamente a "main"
2. Nunca hagas push a "develop" (usa PR en su lugar)
3. Si cometes error, puedes revertir:
   
   git reset --soft HEAD~1  # Deshace el último commit pero guarda cambios
   git reset --hard HEAD~1  # Deshace todo (cuidado!)

4. Si quieres ver cambios antes de commit:
   
   git diff

5. Si quieres cancelar cambios:
   
   git checkout -- modelos/cliente.py  # Deshace cambios en un archivo
